신디 음색

개인정보 및 사용방법 안내

카메라 및 개인정보 안내

이 사이트는 손 동작 인식을 위해 카메라를 사용합니다.

  • 카메라 영상은 사용자의 기기에서 실시간으로 처리됩니다.
  • 영상이나 사진은 녹화·저장되지 않습니다.
  • 카메라 영상이나 사진은 사이트 관리자에게 전송되지 않습니다.
  • 사이트 관리자도 사용자의 카메라 화면을 확인할 수 없습니다.

카메라는 손의 위치와 동작을 인식하는 용도로만 사용됩니다. 사이트 실행에 필요한 프로그램 파일과 손 인식 모델은 인터넷을 통해 불러올 수 있습니다.

사용방법

1. 카메라와 소리 시작

왼쪽 위의 카메라 + 소리 시작 버튼을 누르고 카메라 사용을 허용합니다. 모바일에서는 소리가 작게 들릴 수 있으므로 기기 음량도 확인하세요.

2. 이 사이트에서 말하는 '검지를 편 상태'

검지 손가락을 손바닥에서 앞으로 가능한 곧게 펴는 자세입니다. 다른 손가락은 펴거나 접어도 상관없으며, 검지의 상태를 중심으로 판단합니다. 검지가 충분히 펴진 상태에서 코드원 위의 원하는 영역을 가리키면 코드가 선택됩니다.

3. 이 사이트에서 말하는 '검지를 접은 상태'

검지를 손바닥 쪽으로 충분히 구부린 자세입니다. 주먹을 완전히 쥐어도 되고 검지만 접어도 됩니다. 검지를 접으면 현재 선택이 해제되고 해당 손의 소리가 멈춥니다.

4. 코드 선택과 정지

검지를 편 채 코드원의 원하는 칸을 가리켜 선택합니다. 검지를 접거나, 손가락이 코드원 영역 밖으로 벗어나면 해당 손의 소리가 자동으로 멈춥니다.

5. 기본 모드

한쪽 코드원에서 근음(C, D, E, F, G, A, B)을 고르고 다른 코드원에서 maj, m, 7, m7 등의 코드 타입을 고릅니다. 두 선택이 조합되어 하나의 코드가 연주됩니다.

6. 사용자 코드 모드

셋업에서 원하는 코드 이름을 직접 입력해 코드원에 배치할 수 있습니다. 이 모드에서는 왼손과 오른손이 각각 독립적으로 동작하므로 서로 다른 두 코드를 동시에 연주할 수도 있습니다.

셋업 사용방법

모드

기본 모드 - 양손은 근음 + 코드 타입을 조합하는 방식입니다. 사용자 코드 모드는 원하는 코드 이름을 직접 등록하는 방식입니다.

카메라

모바일에서는 전면/후면 카메라를 선택할 수 있습니다. 저장하면 선택한 카메라로 다시 시작됩니다.

손 인식 엔진 / 성능 모드

손이 잘 인식되지 않으면 CPU - 호환성을 권장합니다. 화면 반응이 느리면 프레임 우선을 사용해 보세요. GPU가 빠르더라도 일부 기기에서는 손 검출이 되지 않을 수 있습니다.

검지 보정 — 처음 사용할 때 권장

사람마다 손 모양과 카메라 각도가 달라서 왼손과 오른손을 각각 따로 보정하면 검지 펴기/접기 판정이 훨씬 안정적입니다.

  1. 카메라에 해당 손을 잘 보이게 한 뒤 검지를 가능한 곧게 폅니다.
  2. 그 자세를 유지하면서 해당 손의 완전히 펴짐 저장을 누르고 약 0.8초 동안 그대로 유지합니다.
  3. 이번에는 검지를 손바닥 쪽으로 최대한 접습니다.
  4. 완전히 접힘 저장을 누르고 약 0.8초 동안 그대로 유지합니다.
  5. 왼손과 오른손을 각각 같은 방법으로 보정한 뒤 맨 아래의 저장을 누릅니다.

'현재 원시값'은 참고용 숫자입니다. 숫자를 직접 맞출 필요 없이 실제로 가장 접은 자세와 가장 편 자세를 저장하면 됩니다.

기본 모드의 코드 타입

오른쪽 코드원에 넣을 코드 타입과 개수를 바꿀 수 있습니다. 예: maj, m, 7, maj7, m7, 6, m6, 9, add9, 7sus4 등.

사용자 코드 모드의 코드 입력

코드원 칸 수를 정한 뒤 각 칸에 원하는 코드를 입력합니다. 예: Cadd9, A9, E6, CmMaj7, F#m7b5, G7b9, C6/9, C/E 등.

음량

사이트에서 출력하는 신디 음량을 조절합니다. 기기 자체의 미디어 음량과 별개이므로 둘 다 확인해야 합니다.

모바일 스피커 보강

휴대폰 스피커에서 낮은 음이 너무 작게 들릴 때 사용합니다. 값을 높이면 한 옥타브 위 성분이 더 섞여 코드가 더 잘 들리지만, 너무 높이면 음색이 밝아질 수 있습니다.
